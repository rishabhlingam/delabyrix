## Changes

### [`backend/pipeline/pii_redactor.py`](backend/pipeline/pii_redactor.py)

**Root cause 1 — name regex was ASCII-only:**  
The old `_NAME_HEURISTIC` used `[A-Z][a-z]{1,20}` which skipped `María` (accent on `a`) and `García` (accent on `i`). Fixed by introducing `_NAME_PART` — a character class that includes the full Latin-Extended block (`\u00C0-\u00D6`, `\u00D8-\u00DE`, `\u00DF-\u00FF`), and rebuilding both the heuristic and the new contextual regex from it, with `re.UNICODE`.

**Root cause 2 — no contextual name phrase patterns:**  
Added `_NAME_CONTEXTUAL` — a high-priority pass that fires on `"I am <Name>"`, `"My name is <Name>"`, `"Me llamo <Name>"`, `"Soy <Name>"`, `"My patient is <Name>"`, and `"मेरा नाम <Name> है"` before the general heuristic runs. `_redact_names()` now runs contextual first, then the heuristic.

**Root cause 3 — alphanumeric ID format unrecognised:**  
`12345678A` (digits-then-letter) didn't match `_PASSPORT` which only handled `[A-Z]{1,2}\d{6,9}` (letters-then-digits). Added `|\b\d{7,9}[A-Z]\b` to `_PASSPORT`.

**Root cause 4 — no keyword-prefixed ID pattern:**  
Added `_ID_KEYWORD` to match `"ID number …"`, `"ID: …"`, `"DNI …"`, `"NIE …"`, `"Passport …"`, `"Pasaporte …"`, `"Número de identificación …"` and replace the whole phrase with `[REDACTED_ID]`.

**Token rename:** `[ID]` → `[REDACTED_ID]`, `[NAME]` → `[REDACTED_NAME]` for clarity in the reviewer UI.

### [`backend/routers/agent.py`](backend/routers/agent.py)

**Root cause 5 — translation could expose PII missed in Stage 0:**  
Added a second-pass `redact()` call on the English-translated text when `source_language != "en"`. PII types newly discovered in the translated form are merged into the primary redaction result so HITL escalation rules (Rule 3) account for them.
