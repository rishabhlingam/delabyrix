# Ask Mode Rules

This file provides guidance to agents when working with code in this repository.

## Documentation Context

- The **only authoritative project description** is `idea.txt` in the repo root — treat it as the source of truth for scope and requirements until formal specs are written.
- There are **no docs, README, or API specs yet** — do not invent them; surface the gap to the user instead.
- The three user groups (foreign patients, healthcare providers, care coordinators) have distinct UX and compliance needs — answers about features must be scoped to the relevant user group.
- "Translation" in this project means **medical/cultural interpretation**, not just language translation — answers conflating the two will mislead.
